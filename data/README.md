# Dados

O projeto foi construído a partir do arquivo de exercício `Dados_Indendio.csv`.

Por opção de versionamento, o arquivo original não está incluído neste repositório público.

Para reproduzir a análise:

1. crie a pasta `data/source/`;
2. adicione o arquivo com o nome `Dados_Indendio.csv`;
3. execute `python -m src.analysis`.

O código espera as colunas:

`year`, `state`, `month`, `number`, `date`.

A leitura usa codificação `latin1`, conforme o arquivo analisado.
